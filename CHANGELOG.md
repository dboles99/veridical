# Changelog

## 2.0.0

First release. Five modules: Flanger, Chorus, Phaser, Ring Mod, Env Follower.

All five are polyphonic to sixteen channels and stereo, with the right input
normalled to the left. Every continuous parameter has a CV input and an
attenuverter.

Dark and light panels on every module, chosen from the right-click menu and
saved with the patch.
